# 📄 AI Document Assistant

An AI-powered document assistant built with Python, Streamlit, and Google Gemini.

## 🚀 Features

* Upload PDF and TXT documents
* Generate document summaries
* Ask questions about uploaded documents
* Get responses in English and Telugu
* Download summaries as text files

## 🛠️ Technologies Used

* Python
* Streamlit
* PyPDF
* Google Gemini API

## ▶️ How to Use

1. Open the deployed Streamlit app.
2. Upload a PDF or TXT document.
3. Generate a summary or ask questions about the document.
4. Choose Telugu or English if language selection is available.
5. Download the summary if needed.

## 🔐 Security

The Gemini API key is configured through Streamlit Secrets. Never commit API keys, passwords, or private documents to GitHub.

## 📦 Run Locally

Install the dependencies:

```bash
pip install -r requirements.txt
```

Run the app:

```bash
streamlit run app.py
```

## 👨‍💻 Project Purpose

This project demonstrates AI-powered document summarization and question answering using Python and Google Gemini.
